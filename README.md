## 🚀 Project Overview

**Rural ERides Go** is a production-grade React, Vite, and Capacitor mobile application engineered and heavily field-tested in Stigler, Oklahoma[cite: 8]. Designed exclusively for electric personal vehicle (PEV) enthusiasts, this app bypasses closed-ecosystem restrictions to deliver high-precision telemetry monitoring, live GPS breadcrumb routing, and a global community network[cite: 8].

This application officially launched in tandem with the **150 Subscriber Milestone** on the Rural ERides channel, celebrating a growing community of rural riders and open-source tech enthusiasts!

## ✨ Core Architecture & Features (V7.4.0)

Version 7.4.0 transforms the app into a full-scale PEV operating system packed with deep hardware integrations:

* **Live GPS Breadcrumb Routing:** The telemetry engine secretly drops GPS waypoints every 0.05 miles. Broadcasting a run to the Community Board generates an interactive, multi-waypoint Google Maps route of your exact path.
* **Predictive Maintenance Physics:** The diagnostic dashboard tracks Tire Tread Life, Brake Pad Wear, Drivetrain integrity, and Battery Health/Voltage Sag based on lifetime telemetry mileage[cite: 10].
* **Native Push Notifications:** Capacitor hooks are fully active. Community pings, Crew Invites, and Secure Comms trigger native OS background alerts.
* **Creator God-Mode & The Board:** The Universal Feed features an Admin override for moderating global transmissions, dynamic Sector Turf Wars leaderboards, and instant auto-snap navigation.
* **Ironclad Legal Protocol:** A mandatory 7-point onboarding briefing handles liability, traffic laws, and high-voltage battery warnings with automatic routing straight to the Secure Pilot Registration portal.
* **Financial & Environmental Impact:** Automatically calculates total financial savings, gas saved, car wear avoided, CO2 reduced, and cent-per-mile operating costs[cite: 10].
* **The "Omnibus" Settings Engine:** Deep UI customization including Dynamic Island alerts, Glassmorphism intensity controls, Swipe Navigation, and Background Textures.
